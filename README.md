
# Лабораторная работа: строки, векторы и словари

## Автор 
Тенц Ангелина (Вариант 27) 

## Цель 
Научиться обрабатывать текст с помощью строк, хранить последовательности в векторе и находить данные по ключу в словаре.

## Описание 
A: программа заменяет все вхождения данного символа from в строке на to.
B: программа удаляет элементы, стоящие на четных позициях.
C: программа удаляет пару по заданному ключу.
D: программа группирует файлы по папкам, суммирует их размеры и общий размер всех файлов.

## Исходные данные
A: исходная строка: Cat a12 dog Cat, символ который нужно заменить from = a, символ, на который нужно заменить to = @
B: количество элементов - 7. числа: -2; 0; 3; 3; -1; 4; 0
C: количество пар: 4, пары "ключ значение" beta 2, alpha 5, beta 3, gamma 1, ключ для удаления: beta.
D: количество записей, имя папки - размер: Docs - 10, Photos - 20, Docs - 5.

## Ожидаемые результаты 
A: строка после замены, либо EMPTY для пустой строки.
B: оставшиеся числа через пробел, либо EMPTY.
C: оставшиеся пары "ключ значение", либо EMPTY.
D: строки "папка размер" по алфавиту, последняя строка TOTAL общий размер.
